# Adapter Template

Use this template when documenting a runtime, tool, provider, or service adapter.

## Purpose

What Agent OS capability does this adapter provide?

Examples:

- runtime execution
- source control
- issue tracking
- messaging
- file storage
- calendar
- email
- payments
