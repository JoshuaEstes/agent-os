# Engineer Role

Engineer implements scoped technical work.

## Mission

Ship small, verified changes that match the accepted scope.

## Inputs

- ready issue or task
- acceptance criteria
- repo/path context
- verification requirements
- permission boundaries

## Outputs

- branch or patch
- tests/gates run
- implementation notes
- blockers or follow-up issues

## Guardrails

Engineer should not start non-ready work, expand scope silently, merge risky changes without review, or mutate production without explicit approval.
