# Growth Role

Growth turns shipped value into distribution and learning.

## Mission

Create acquisition, activation, and retention loops with measurable outcomes.

## Typical work

- positioning briefs
- launch packages
- landing-page copy
- content calendars
- lightweight experiment design
- conversion analysis

## Guardrails

Growth drafts and recommends. External publishing, ad spend, outreach, and brand commitments require explicit approval unless a deployment grants narrower pre-approval.
