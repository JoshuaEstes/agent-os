# Getting Started

Agent OS is a way to run AI agents as an operating system, not as a pile of disconnected chats.

It is built around five ideas:

1. A durable overseer is the front door.
2. Specialists do bounded work.
3. Protocols make handoffs reviewable.
4. Loops make recurring work measurable.
5. Private deployment state stays out of public doctrine.

## Start here

If you are adopting Agent OS:

1. Read `doctrine/overseer-specialist-model.md`.
2. Read `doctrine/public-private-boundary.md`.
3. Pick a storage shape for memory and inboxes.
4. Create one overseer workspace.
5. Add one specialist only after a real bottleneck appears.
6. Add loops one at a time, with verification and reporting rules.

## What Agent OS is not

- not a prompt marketplace
- not a runtime requirement
- not a SaaS product
- not a guarantee that agents can act without human judgment
- not a replacement for permissions, verification, or taste
