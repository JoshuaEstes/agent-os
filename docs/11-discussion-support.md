# Discussion Support

GitHub Discussions are the public support surface for Agent OS.

## Triage loop

A maintainer support pass should:

1. Read new Discussions and unanswered Q&A.
2. Identify whether each item is a question, idea, bug, or showcase.
3. Answer simple questions directly.
4. Convert concrete repo changes into Issues.
5. Link to existing docs when possible.
6. Capture recurring confusion as documentation work.

## Escalation

Escalate before responding when a discussion asks for:

- security-sensitive guidance
- legal/financial/medical advice
- credentials or private deployment details
- endorsement of a risky automation pattern
- a public roadmap/product commitment

## Good answers

Good support answers are:

- concise
- specific
- safety-aware
- runtime-neutral by default
- honest about uncertainty
- linked to docs or issues when useful

## From discussion to docs

If the same question appears twice, improve the docs. Support should reduce future support load.
