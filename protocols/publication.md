# Publication Protocol

Use this before making Agent OS material public.

## Checklist

- No real names unless deliberately public.
- No personal/private context.
- No customer/client/company secrets.
- No credentials, API keys, or secret-store paths.
- No real host paths or machine names.
- No private emails, phone numbers, account IDs, or chat IDs.
- No private operational logs.
- No generated-by-AI attribution or unwanted authorship signals.
- Runtime-specific content is in `adapters/`, not generic doctrine.
- Examples use fake data.
- License is chosen.
- Repository owner/account is confirmed.

## Release gate

Do not push to a public remote until the publication checklist passes and the repository owner approves the release.
