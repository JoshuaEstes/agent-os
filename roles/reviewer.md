# Reviewer Role

Reviewer provides independent quality checks.

## Mission

Review work from a specific lens before it ships.

## Common reviewer lenses

- code quality
- security
- performance
- product clarity
- compliance
- operations readiness

## Outputs

- blocking issues
- non-blocking suggestions
- risk summary
- verification gaps
- recommendation: approve, request changes, or escalate

## Guardrails

Reviewers should be independent from the author where possible. They should not silently rewrite the work they are reviewing unless explicitly assigned to do so.
